# Changelog

- Adaptasi deployment Flask untuk Vercel Functions dan static assets pada `public/`.
- PostgreSQL production support melalui SQLAlchemy dan Alembic migration.

- Automated CI untuk unit/integration tests, dependency audit, dan syntax checks.
- Dokumentasi project status, QA, provisioning, deployment, dan rollback.
